----------------------------------------------------------------
INSTALL (Windows)
----------------------------------------------------------------
1. STOP the server: Ctrl+C in the run.bat window.

2. EXTRACT this ZIP and MERGE the "frontend" folder into your project at
     C:\Users\Hp\Desktop\git-hub\aapatsetu\
   Click "Replace the files in the destination" when Windows asks.

3. CLEAR CACHES (this is what prevents the "blank page / old map" bug):
     cd /d C:\Users\Hp\Desktop\git-hub\aapatsetu
     rmdir /s /q backend\static
     rmdir /s /q frontend\node_modules\.vite

4. RUN run.bat and wait until you see "✓ built in Xs" in the terminal.

5. OPEN http://localhost:8000/ and HARD-REFRESH: Ctrl+Shift+R
   (the browser also caches old CSS/JS — hard refresh is mandatory).

If anything ever looks wrong, hit Ctrl+Shift+R twice first. If a page
is blank, repeat step 3 — leftover backend/static chunks from older
builds are the #1 cause.

----------------------------------------------------------------
WILL THIS BREAK MY APP?
----------------------------------------------------------------
No. None of the 3 files change routes, API calls, state (zustand),
forms, WebSocket logic, auth, ORS map, Recharts charts, or i18n.
- index.css only ADDS CSS; global overrides use element/class
  selectors that are additive over your existing Tailwind classes.
- ui.jsx only ADDS/UPDATES reusable presentational components; no
  page JSX imports anything new from it that didn't exist before.
- tailwind.config.js only changes color/shadow/font tokens that the
  JSX already references via Tailwind classes like bg-brand-600.

The only visible difference should be: light gray #edf2f9 background,
white rounded-lg cards with soft phoenix shadow, Inter font, red
(#dc2626) brand accents, consistent form controls/badges/tables
everywhere.
